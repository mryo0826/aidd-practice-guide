# AI-Driven Development Practice Guide — English entry

**What this is:** A guide to running AI-assisted software development with discipline. It is not a tool manual; it applies the discipline of Agile/Scrum (inspect and adapt, with a human as the final decision-maker) to working with AI coding agents such as Claude Code.

**Language:** The guide itself is written in Japanese. There is no full English translation, and this page is not one.

**How to read it:** Have an LLM chat read a file and translate or summarize it for your role. The raw Markdown URLs are the easiest form for an LLM to read, for example:

- https://raw.githubusercontent.com/mryo0826/aidd-practice-guide/refs/heads/main/README.md
- https://raw.githubusercontent.com/mryo0826/aidd-practice-guide/refs/heads/main/01_ai-driven-dev-strategy.md

Some of the files are also loaded directly by AI tools (for example, `CLAUDE.md` is loaded by Claude Code at the start of every session).
